# Openest Docs

Documentação centralizada do projeto Openest.

## 📋 Conteúdo

- `/decisions` - Decisões técnicas (ADR)
- `/scripts` - Scripts de banco de dados e utilitários
- `/diagrams` - Diagramas de arquitetura
- `/meetings` - Atas de reuniões

## 🎯 Propósito

Este repositório existe para centralizar toda a documentação do projeto, garantindo que decisões e informações importantes estejam acessíveis a todo o time.

## 📚 Documentação Principal

- [Backend API](https://github.com/openest/openest-api)
- [Frontend Web](https://github.com/openest/openest-web)

## 🤝 Como contribuir

Para adicionar documentação:

1. Crie um branch com o nome do documento
2. Adicione o arquivo na pasta apropriada
3. Abra um Pull Request para revisão
